## 📌 Project Overview

This project is an interactive, single-page web application designed with a modern dark glassmorphism UI. It covers the fundamentals of JavaScript, Document Object Model (DOM) manipulation, event handling, and dynamic element creation.

The application is split into four structured sections accessible via a navigation bar:

- **Part 1: Introduction to JavaScript** (Console outputs, alerts, data types, and arithmetic operations)
- **Part 2: DOM Manipulation** (Changing element content, dynamic styling, and list item management)
- **Part 3: Events** (Mouse hover events, real-time keyboard inputs, and a working math calculator)
- **Part 4: Mini Project — Interactive To-Do List** (In-memory task storage, title/description entries, completion toggle, and task deletion)

## 🛠️ Features & Tasks Implementation

### Part 1: Introduction to JavaScript

- **Task 0 (First Script):** Logs student credentials to the console and triggers an alert message (_"Hello, JavaScript World!"_). Included a virtual terminal log preview directly on the page.
- **Task 1 (Variables & Operators):** Declares `string`, `number`, and `boolean` variables. Demonstrates basic arithmetic operations and string concatenation.

### Part 2: DOM Manipulation

- **Task 2 (Changing Content):** Modifies paragraph inner text dynamically upon button click.
- **Task 3 (Changing Styles):** Updates a `div` element's background color and font size dynamically using JavaScript inline style manipulation.
- **Task 4 (Creating & Removing Elements):** Appends new `<li>` items to an unordered list and removes the last item sequentially.

### Part 3: Events

- **Task 5 (Mouse Events):** Implements `mouseover` and `mouseout` event listeners to transform box styles on hover.
- **Task 6 (Keyboard Events):** Listens to `keyup` events on an input element to mirror text in real-time.
- **Task 7 (Calculator):** Evaluates mathematical expressions (`+`, `-`, `*`, `/`) based on two user-provided numbers, including division-by-zero protection.

### Part 4: Interactive To-Do List App

- **Task 8 (To-Do App):**
- Allows users to create tasks with both a **Title** and a **Description**.
- Stores tasks temporarily in an in-memory array data structure.
- Toggles completed tasks with a strike-through text decoration when clicked.
- Deletes individual tasks from the DOM and state.
